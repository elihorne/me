# Eli Horne Personal Site

Modern Next.js portfolio site for Eli Horne (elihorne.com).

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

```bash
npm run build
npm start
```

## Deploy

This site is designed to be deployed on Vercel or any other Next.js-compatible hosting platform.
